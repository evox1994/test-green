## Запуск в dev режиме

1. Установить зависимости

```bash
npm i
```

2. Запустить команду

```bash
npm run dev
```

## Нюансы

1. Схемы валидаций упрощены до обычного обязательного заполнения
2. Типизация ответов от GREEN-API отсутствует, по хорошему надо типизировать
3. В целом реализована только бизнес логика обмена текстовыми сообщениями
